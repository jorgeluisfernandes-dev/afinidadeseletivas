# AfinidadeSeletivas

Site estático do blog **AfinidadeSeletivas**.

Publicado com GitHub Pages, sem Jekyll.

O conteúdo histórico do blog está organizado por categorias, arquivo cronológico e tags.

A navegação publicada reúne **Obra**, **Afinidades**, **Arquivo**, **Índices** e
**Manifesto**. As páginas de índices usam os arquivos históricos e os textos em
`content/posts/` sem alterar os endereços dos textos. A busca consulta o arquivo
`busca/indice.json` produzido em cada montagem.
