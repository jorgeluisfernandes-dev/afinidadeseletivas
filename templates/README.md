# Templates

O gerador não mantém uma cópia independente do desenho do blog.

Para evitar que o visual de novas publicações se afaste do AfinidadeSeletivas, ele usa como molde as próprias páginas já existentes do site:

- prosa: `archive/2007/10/16/orion.html`
- poesia: `archive/2007/05/06/o-salto.html`

Assim, mudanças futuras no CSS e na estrutura do site continuam sendo herdadas pelas novas páginas.
